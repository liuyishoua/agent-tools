# humanizer-zh 在生活短文中的应用

来源与许可证见 [source.json](upstream-humanizer/source.json) 与 [MIT LICENSE](upstream-humanizer/LICENSE)。已审查上游 SKILL.md，实际采用的是 [sentence-diagnostics.md](upstream-humanizer/sentence-diagnostics.md) 中的中文句式诊断。

先看草稿最明显的一处问题，再查对应诊断章节：机械对照句、翻译式连接、空泛判断、口号收尾、列表排比、标点、营销腔、判断强度、主线脱节、预告式结尾和抽象重锤句。把问题定位到具体句子后再改，不建立“出现某词就删除”的黑名单。

诊断中的修改前后例句用于说明句法，不是本轮事实来源；不能移植其中的产品、公司、时间和数值。标点与段落习惯服从账号已有表达及平台任务，不把长文规范强加给私信或短笔记。

本集成保留原意、事实与信息密度，允许改句序、合并重复和删除空泛拔高。需要生活观察才调用同场景研究；需要改变主人事实时先回到任务依据，不用优美句子填空。

未接入上游的名家 voice、作者身份、语料库索引、主动询问用户挑作者、长篇文章模板、PR译名约定和全局标点禁令。主 Skill 的账号 persona、事实边界、统一 ContentPackage 和本轮授权始终有效。
