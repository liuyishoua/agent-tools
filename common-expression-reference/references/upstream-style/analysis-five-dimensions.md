# 风格分析：已选上游五维章节

以下保留上游 analysis-framework.md 第3节。字段取舍与StyleCard转换由 ../style-card-adapter.md 决定。

## 3. 通用五维分析

任何文章都跑这 5 维。每个维度的产出**最终要落到** `style_profile.yaml` 对应字段（schema 见 `style-profile-schema.md`）。

### 维度一：标题术 → `title_craft`

#### 需要采集的数据点

| 指标 | 采集方法 | 进入档案的字段 |
|------|----------|---------------|
| 标题字数 | 统计每个标题字符数，取平均和分布 | `avg_length`, `length_range` |
| 信息层数 | 每个标题包含几个独立信息单元 | `info_density` |
| 标点类型 | 各标点出现频率 | `punctuation_usage` |
| 数字使用率 | 含精确数字的标题占比 | `number_usage_rate` |
| 人名 / 品牌出现率 | 含命名实体的标题占比 | `named_entity_rate` |
| 情绪词 | 标题中所有情绪词按频率排序 | `emotion_words` |
| 对立结构 | 是否使用"从X到Y""别人X，它偏Y"式对立 | 写入 `notes` |

#### 标题公式提炼方法

将所有标题的结构抽象化，归纳为可填空的模板（3-7 条），每条必须配一个真实样本例：

- `[主体] + [动作] + [结果/数据]` → "OpenAI 收购 Astral，Python 包管理神器 uv 现在姓 O 了"
- `[反常识事实]，[情绪反应]！` → "性能超 GPT-5，完全端侧运行！"
- `[主体A] vs [主体B]，[悬念]` → 对立结构

写入 `title_craft.formulas`。

### 维度二：开篇手法 → `opening_craft`

#### 钩子类型库

| 钩子类型 | 特征 | 适用场景 |
|----------|------|----------|
| 震惊式 | 感叹号 + 加粗核心事实 | 突发新闻 |
| 立场式 | 第一句就表态 / 情绪 | 争议事件 |
| 反常识式 | 反直觉的事实陈述 | 人物 / 深度 |
| 痛点式 | "苦于X？"式提问 | 产品 / 技术 |
| 社区式 | 用昵称打招呼 | 系列栏目 / 社群 |
| 引语式 | 直接引用名人原话 | 访谈 / 人物 |
| 数据式 | 用一个惊人数字开场 | 行业 / 财经 |
| 场景式 | 描述一个具体场景 | 深度长文 / 故事 / 散文 |

统计每种钩子类型出现的次数和占比 → `hook_distribution`。

对前 3 名钩子（`preferred_hooks`），每个写出"可复用模板 + 真实样本例"，进入 `hook_templates`。

#### 开篇节奏测量

- 第一句话字数 → `first_sentence_avg_chars`
- 前 3 句话总字数
- 前 3 句话完成了什么任务（给信息 / 造情绪 / 设悬念）
- 背景信息出现在第几段 → `background_placement`（early / late）

#### 人称偏好

统计开篇 200 字内"你/我/我们"出现密度 → `pronoun_usage`。

### 维度三：段落节奏与结构 → `rhythm`

#### 节奏序列标注

取 3-5 篇文章，对每一段标注类型：
- **L** = 信息段（2-3 句话，给事实）
- **S** = 极短段（1 句话 / 几个字，给情绪或转折）
- **I** = 图片 / 截图
- **Q** = 引用块
- **H** = 小标题

序列示例：
```
L-L-S-I-L-S-L-L-I-S-L-H-L-L-S-I-L-Q-S-L
```

寻找重复模式 → `rhythm_pattern`，加自然语言注释 → `rhythm_pattern_notes`。

#### 段落长度统计

- 每段平均句数 → `avg_sentences_per_paragraph`
- 极短段（≤8 字独立成段）出现频率 → `short_paragraph_rate`
- 最长段和最短段的落差（写入 `notes`）

#### 小标题

- 是否使用 → `uses_subheadings`
- 风格特征（信息密度 / 是否带情绪）→ `subheading_style`
- 一个典型例子 → `subheading_style.example`

#### 图片节奏

每隔多少段出现一张图 → `image_frequency`（自然语言，如 "every 4-5 paragraphs"）。

#### 段间过渡

记录主要过渡方式 → `transition_style`。

### 维度四：语言风格 → `language_style`

这是最核心的维度，需要分多个子层面拆解。

#### 4.1 动词采集 → `power_verbs`

精读时逐篇记录所有**非通用**动词。"非通用"指：能被替换成更平淡的中性词的、带情绪倾向的动词。

| 原文动词 | 出现次数 | 替代了什么中性词 | 情绪强度(1-5) | 情感极性 | 示例原句 |
|----------|----------|------------------|--------------|----------|----------|
| 炸出 | 4 | 发布 | 5 | positive | "OpenAI 又炸出新模型" |
| 锤 | 3 | 批评 | 5 | negative | "网友把这家公司锤上热搜" |

按频率排序，取 top 20-30 → 写入 `language_style.power_verbs`（每条带 `example`）。

#### 4.2 语气色板 → `tone_palette`

语气档位库（不是每个作者都有 5 档，找出该作者实际用的几档）：

| 语气档位 | 判断特征 |
|----------|----------|
| 正经/严肃 | 完整句、书面语、引用数据 |
| 口语/轻松 | 缩略语、语气词（嘛/呗/啊）、短句 |
| 调侃/戏谑 | 自创词、引号反讽、"doge" 类标记 |
| 震惊/感叹 | 感叹号、"我勒个""什么？！"、加粗 |
| 诗意/升华 | 排比、意象、金句、哲理 |
| 学术/专业 | 术语密集、论文式表达 |
| 煽情/热血 | 排比递进、呼吁行动、民族自豪 |
| 冷峻/克制 | 短句、不带情绪词、留白 |

输出：
- 实际使用的几档 + 各档占比 → `tone_palette` 列表
- 切换规律 → `tone_transitions`
- 禁区档位 → 进 `forbidden`

#### 4.3 标点功能 → `punctuation_rules`

| 标点 | 需要观察的功能 |
|------|---------------|
| 加粗 | 信息锚点 / 情绪强调 / 品牌高亮 |
| 引号「」/"" | 引用原话 / 反讽 / 概念高亮 |
| 破折号—— | 解释补充 / 制造悬念 / 语气延伸 |
| 省略号…… | 犹豫 / 留白 / 省略 |
| 多问号？？？ | 真提问 / 情绪外化 |
| 感叹号！ | 使用频率、是否克制 |

每个标点记录 `function` + `density`（high/mid/low）+ 至少 1 个 example。

#### 4.4 口头禅 → `signature_phrases`

记录所有反复出现的短语 / 句式：
- 转折连接词（"这不，""谁曾想，""但问题来了，"）
- 评价短语（"怎么说呢""不得不说""属实""绝了"）
- 情绪词（"炸""绝""顶""离谱"）
- 开头短语（"划重点""先说结论"）
- 自创词 / 昵称（同时进 `custom_vocabulary`）

按出现频率排序，标注每个表达出现的典型语境 → `context` 字段。

#### 4.5 技术 / 抽象概念处理 → `technical_concept_handling`

仅当样本涉及技术 / 抽象内容时填：
- 是直写专业术语，还是必配类比？
- 类比的偏好来源（日常生活 / 游戏 / 影视 / 军事…）
- 给一个最典型的样本例

#### 4.6 自创词典 → `custom_vocabulary`

列出作者的自创词 / 昵称（粉丝称呼、产品昵称、编辑部自称等），逐个解释。

### 维度五：结尾模式 → `ending_craft`

#### 结尾类型库

| 结尾类型 | 特征 | 效果 |
|----------|------|------|
| one_more_thing | 文末彩蛋 / 延伸信息 | 训练完读 |
| poetic_summary | 排比 / 意象 / 升华 | 情绪高峰收尾 |
| open_question | 反问 / 留白 | 引发讨论 |
| cta | "试试看""链接在这" | 转化 / 互动 |
| summary | 一段话概括全文 | 信息闭合 |

统计各类型占比 → `ending_type_distribution`，提取前 2-3 名 → `preferred_endings`，每个写"模板 + 样本例" → `ending_templates`。

如果存在固定 CTA（如"点赞 + 关注"段），完整摘录 → `fixed_cta_text`。
