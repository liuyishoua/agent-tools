# 人物形象与生活片段

产物是人物主导的 ContentPackage。账号身份、审美与说话方式来自任务 context.persona；平台标题长度、排版和发布字段交给平台 Skill。

## 取得可用输入

- 读取本轮目标、账号已确认事实、授权人物参考、服装与场景要求、已有素材和最近内容。
- 区分真人授权参考、已建立的虚拟人物、尚未确定的形象。只有任务允许建立虚拟人物时才创建新形象；不能把网上搜到的人认作账号主人。
- 已有虚拟人物与已授权生成照可以继续使用，不因“不是实拍”丢弃；来源与合成状态保存在内部 media 元数据。
- 没有亲身经历也可创作穿搭灵感、人物视觉或场景设定；标题正文不能据此声称主人今天到访、训练或购买。

## 先定人物，再导演画面

1. 从真实参考提取本轮身份锁：脸部轮廓、发型、体形比例、明显特征与风格。区分稳定身份与本次可变的衣服、表情和姿态。
2. 用一句话确定人物正在做的事，例如“刚停下来系鞋带”。行动决定构图；避免所有图都直视镜头摆同一姿势。
3. 设计有作用的画面组合：一张建立人物与场所关系，一张动作或服装细节，必要时一张环境补充。图数服从内容，不能换裁切凑数。
4. 让服装、动作与环境互相成立：鞋底接地、器械接触点、布料受力、影子方向、风向、温度。身材表达优先姿态和镜头关系，不靠不可能的比例。
5. 按任务可用工具执行生成或编辑。已有参考优先走参考图编辑；生成新人物时保留选中的基准图作为后续身份参考。
6. 实际查看每张候选图；不能用生成成功、文件名或提示词代替看图。失败时针对具体问题重做，不无限添加“高质量、真实”形容词。

## 配文与人物连续性

- 先写画面里可见的动作和一个符合人设的态度，文字与照片分工，避免把画面逐项复述。
- 生活感来自具体取舍，例如穿什么走得舒服、照片里看中了哪处光；不要额外捏造下班时间、运动成绩或关系经历。
- 如果这次延续已发布的人物，逐图对照身份锁；同组自拍与远景也必须像同一个人。
- 美感按账号审美判断，不把磨皮、瘦身、夸大曲线设为默认质量标准。
- 如任务只要求图片，body 可以为空；不要为“完整笔记”多造故事。

## 输出

返回 ContentPackage：

```json
{"title":"候选标题","body":"正文","media":[{"attachment_id":"真实附件ID或省略","role":"首图/动作/细节","viewed":true,"source_url":null,"internal":{"identity_ref":"本轮参考","origin":"authorized_photo|generated|edited","usage_basis":"授权或许可依据"},"path":"真实文件或省略","origin":"owner|licensed|generated","usage_rights":"授权或许可依据","generated_label_required":false}],"source_refs":[],"claims":[{"text":"经历类陈述","basis":"任务确认事实","status":"confirmed","kind":"verified_fact|preference|creative"}],"quality":{"status":"ready|hold","observations":[],"missing":[],"identity_consistent":true,"physical_consistent":true}}
```

- path、attachment_id 至少有一个能定位实际产物；不虚构附件ID或尚未生成的图。
- 工具不可用时保留可完成的文字和具体缺项，media 为空，quality.missing 说明未执行项，不把图片提示词当成照片交付。
- 身份、来源和合成记录供内部检查；需要的公开标识由平台 Skill 按实际规则处理。

- 统一 ContentPackage：media 使用 path/source_url/origin/usage_rights/generated_label_required/viewed，claims 包含 text/basis/kind，quality 包含 status/observations/missing；检查完成且无缺项才 ready，否则 hold。

## 示例与验收

任务：“用这个授权人物做一组阴天城市散步照，黑色运动套装，配一句轻松文案。”

独有验收：遮住标题后，首图、动作图与细节图仍能认出同一人物，而且衣服、身体接触与天气相互成立。

## 账号资料边界

身份、口吻、固定视觉形象与历史由当前账号档案提供；本技能不保存专属人设。创作中的虚拟设定与现实经历分开，公开资料只作参考，不当作账号亲历。
