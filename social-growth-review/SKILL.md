# 社交·账号成长·复盘表现

输入同账号、同时间窗的发布清单、实际曝光/阅读/互动等可用指标与内容目标；明确缺失指标和样本量。不能把没有抓取到的指标填零或生成虚构增长。
比较同口径内容，区分观察、原因假设与可验证的下一步；评论和私信内容按需求主题汇总，不把个别评论当整体受众事实。输出时间窗、数据覆盖、作品比较、发现及证据、有限候选实验、下一轮调整。改变账号稳定身份或自动化权限不属于复盘动作；新偏好由 memory skill 核实。

身份、平台和执行账号由任务/账号档案提供。只处理绑定账号资料，不读取其他账号历史；真实发送沿用已有授权和工作台执行，不由分类或记忆变更开启。
