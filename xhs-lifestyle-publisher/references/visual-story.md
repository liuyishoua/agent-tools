# 用照片讲一个生活片段

用户指定参考：李一桐，小红书认证账号，https://www.xiaohongshu.com/user/profile/5f686d100000000001003b18 。2026-10-10通过已登录的小红书网页接口读取首屏公开笔记，并实际用浏览器查看最近四篇封面；没有声称看完账号所有图片、测得流量因果或获得转载许可。

实际观察：

- 窗边近景有明确自然光，人物、手部与包形成前后层次；不能把有品牌露出的商业图简单当普通生活实拍模板。
- 夜街图让穿搭人物与店铺、路面一起入镜，地点与动作比一个纯色背景更像一个瞬间。
- 庭院穿搭用远一点的构图保留身体轮廓和环境纵深；首图不仅是展示局部。
- 店门口图中人物与巨大冰淇淋道具互动，表情、姿势和物体关系已经承担笑点，短标题起点题作用。

应用到小桃：

1. 先定视觉动作：走路、拿杯子、翻书、靠窗、整理一小块台面。画面里要有可说的东西，不只选“漂亮”但无关的图。
2. 首图有清楚主体、合理光线与构图。人物穿搭可以自然展示轮廓和姿态，但不能用陌生人的脸虚构持续人物身份，也不能把别人的身材当本人实测结果。
3. 2–6图各有作用：首图抓注意；第二张补环境；第三张可给物件或动作细节；其余只有能补信息才保留。不是固定张数模板，同一场景不足时宁可换主题，不凑互相矛盾的画面。
4. 文字服从照片。生活灵感类可以一句观察加一个轻包袱；方法类才展开操作。照片没有展示的购物、体验和地点，不写成本人刚经历过。不同场景可以公开作为灵感参考，不能虚构连续行程。
5. 看完整组再定稿：光线和情绪是否协调，顺序是否顺，包袱是否需要解释很久，是否像广告图拼贴。热点只加到有关系的细节里。

明星的外形、知名度和品牌资源不能由构图技巧替代。没有授权的人物实拍时，先做物件、场景与生活灵感；未来有本人图库再做持续的个人穿搭叙事。
